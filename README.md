# Harbor-Island-Deals
### Hermes Studio Coupon Finder

## About the Project
Harbor Island Deals is a responsive coupon and deal finder designed for Harbor Island Marina employees. The application helps employees discover savings on maritime supplies by making relevant deals easier to search, filter, and evaluate.

## Project Goals
- Provide a user-friendly interface for discovering deals.
- Allow users to search, filter, and sort available offers.
- Display relevant deal information and direct users to deal sources.
- Identify expired, invalid, or discontinued offers.
- Deliver a responsive experience across desktop and mobile devices.

## Core Features
- Deal browsing and search
- Category filtering and sorting
- Individual deal details and source links
- Deal validation and expiration management
- Responsive user interface
- Database-backed deal records

## Technology Stack
- Frontend: Typescript / JavaScript, React, Next.js, Tailwind CSS
- Backend: Python, FastAPI, SQLAlchemy
- Database: PostgreSQL, Redis
- Development tools: Git and GitHub
